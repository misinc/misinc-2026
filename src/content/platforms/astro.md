## What Astro is

A modern framework that produces plain, static HTML. No database queries when someone visits, no heavy JavaScript framework loading before your text appears — just finished pages served instantly from a CDN.

The site you are reading is built with it.

## Why we use it

**It is genuinely fast.** Static HTML is the fastest thing the web can serve. That shows up in Core Web Vitals, in search rankings, and in whether someone on a phone waits for your page.

**Search engines and AI assistants love it.** Clean, semantic, server-rendered HTML is the easiest thing for a crawler to read — which matters more every year as assistants start answering questions about local businesses.

**Nothing to attack.** No database, no admin login, no plugins. The attack surface that makes other platforms a maintenance burden mostly does not exist here.

**Hosting is free or nearly free.** Static files cost almost nothing to serve.

**You own it outright.** The site lives in version control as files. Every change is recoverable, nothing is trapped in a proprietary editor, and any competent developer could pick it up. That is deliberate — we would rather you stayed because the work is good than because leaving is hard.

## What to know before choosing it

**Editing is different.** There is no drag-and-drop visual editor by default. Content lives in markdown files, or we connect a headless CMS if you need one. For a site that changes weekly this is fine; if you want to redesign a page yourself on a Sunday afternoon, [Webflow](/platforms/webflow) fits better.

**It needs a developer for structural change.** Adding a new kind of page is a development task, not a client task.

## When we recommend it

Sites where speed and SEO are the priority. Content-heavy sites and large migrations. Anything that needs custom functionality or a database behind it — which is where it pairs naturally with [Supabase](/platforms/supabase). And anyone who wants to own their stack outright with no monthly platform fee.
